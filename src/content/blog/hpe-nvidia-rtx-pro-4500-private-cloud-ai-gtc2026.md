На конференции GTC 2026 HPE сделала сразу три анонса в партнерстве с NVIDIA. Все три касаются разных уровней AI-инфраструктуры: вычисления на уровне сервера, масштабирование кластера и хранение данных. Разбираем каждый по порядку.

## RTX PRO 4500 Blackwell Server Edition в ProLiant

HPE добавила поддержку NVIDIA RTX PRO 4500 Blackwell Server Edition в линейку серверов ProLiant. Это GPU класса enterprise — не датацентровый HGX, а карта для рабочих станций и серверов начального уровня AI, ориентированная на корпоративных пользователей с требованиями по надежности, ISV-сертификациям и долгосрочной поддержке.

RTX PRO 4500 на архитектуре Blackwell закрывает нишу между NVIDIA RTX для воркстейшнов и полноценными ускорителями Instinct/H-серии. Для компаний, которые разворачивают on-prem AI без необходимости в многокиловаттных HGX-системах, это рабочий вариант — меньший TDP, стандартный форм-фактор PCIe, привычная экосистема CUDA.

## Private Cloud AI: масштабирование до 128 GPU

HPE масштабировала свое решение Private Cloud AI — теперь оно поддерживает конфигурации до 128 GPU. Это достигается через новые rack extension модули, которые позволяют наращивать вычислительные узлы без перестройки базовой архитектуры.

128 GPU в одном private cloud-кластере — это серьезная конфигурация для on-prem. Она перекрывает потребности большинства корпоративных задач: fine-tuning моделей до 70B параметров, production inference с несколькими репликами, параллельные исследовательские нагрузки. При этом вся инфраструктура остается внутри периметра компании, что критично для финансового сектора, медицины и государственных структур.

## HPE Alletra Storage MP X10000: первое NVIDIA-Certified Storage

Пожалуй, самый интересный анонс из трех. HPE Alletra Storage MP X10000 получила сертификацию NVIDIA — это первая object storage платформа с таким статусом.

NVIDIA-Certified Storage — это не просто маркетинговый знак. Сертификация подтверждает, что платформа соответствует требованиям NVIDIA по трем параметрам: производительность (пропускная способность и IOPS для AI-нагрузок), безопасность (защита данных, контроль доступа) и масштабируемость (поведение под нагрузкой при росте кластера).

Для AI-инфраструктуры хранилище — нередко узкое место. Обучение больших моделей требует непрерывного стриминга данных с высокой пропускной способностью. Если storage не успевает кормить GPU, вычислительные блоки простаивают. NVIDIA-Certified Storage снимает часть неопределенности при выборе: система проверена именно под AI-нагрузки, а не просто под общие enterprise-сценарии.

## Общая картина

HPE последовательно строит полный стек для enterprise AI: от одиночных серверов ProLiant с GPU до многоузловых кластеров Private Cloud AI и сертифицированного хранилища. Партнерство с NVIDIA здесь — не просто OEM-соглашение, а совместная сертификационная работа, которая дает покупателям предсказуемость при планировании инфраструктуры.

Для организаций, которые хотят строить AI on-prem, не собирая стек из разрозненных компонентов, такой интегрированный подход снижает риски внедрения. Вопрос цены по-прежнему остается: HPE не относится к бюджетному сегменту, и ROI придется считать внимательно.
